# Calculator Master

Project Description
A menu-driven Python calculator developed using Git and GitHub branching workflow. The final version integrates addition, subtraction, multiplication, and division into a single application, with input validation and division-by-zero handling.

Branch Structure
- `addition_Audencial` – implements the addition function
- `subtraction_Audencial` – implements the subtraction function
- `multiplication_Audencial` – implements the multiplication function
- `division_Audencial` – implements the division function, including division-by-zero handling

Program Features
- Menu-driven interface with options for addition, subtraction, multiplication, division, and exit
- User input validation (rejects non-numeric input and re-prompts)
- Division-by-zero handling with a clear error message instead of a crash
- Continuous execution in a loop until the user selects Exit
- Modular function definitions, one per operation

How to Run
```bash
python3 calculator.py
```
